# illustrationLogicBdd
イラストロジックの全解列挙プログラム

## 概要
イラストロジックの全ての解をBDDを利用して列挙するプログラムです<br>
2024年度の卒業研究に使用したものになります

## 使い方
卒業研究に使用した pyファイル と cppファイル を同梱しておきます<br>
PythonソースについてはQRコードの作成、検証を行うおまけみたいなもんです

### コンパイル
```
g++ -o ilb.out -Iinclude ILB_v40_NoQR.cpp -fopenmp
./ilb.out hint1.txt
```
- `-fopenmp` を指定しておくと並列化となり高速に処理できます

### 各ソースについて
一応履歴を残しておきますが、通常のイラストロジック解析なら `ILB_v40_NoQR.cpp` を使用することをお勧めします。

|ファイル名|概要|
|-|-|
|ILB_v1_int.cpp|初版<br> 状態管理に int を使用しているので大きい盤面だとすぐメモリ不足に|
|ILB_v2_unlog_int.cpp|ログを出さない分少し早くなったけどやっぱり int 使用がネック|
|ILB_v3_char.cpp|状態管理に char を使用しているのでそこそこ高速|
|ILB_v40_NoQR.cpp|**普通にイラストロジックを解くなら**<br>多分これが一番早いと思います|
|ILB_v43_qrReady.cpp|卒業研究用に QRコードを解とするイラストロジック に特化したもの|

### ヒントの渡し方
以下の仕様に沿った テキストファイル を引数として渡してください<br>

なお、`hint_viewer`関数を使用することでヒントを正常に読み取れたか確認することが出来ます。

```
縦の長さ, 横の長さ, ヒントの最大個数
縦のヒント
横のヒント
```

例:
```
5,5,2
1,1
1,1
1
1
5
1,1
1,1
1
5
1
```

### 出力
- 解の出力は `output_###.pbm` の名前(`###`は数字)で PBMフォーマット で出力します<br>
  - PBM画像は [IrfanView](https://www.irfanview.com/) などのソフトウェアでPNG等の汎用画像ファイルに変換できます
